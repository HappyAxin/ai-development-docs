# AI 辅助开发过程文档规范

## 1. 目标

文档用于回答五个维护问题：为什么改、准备怎样改、实际改了什么、如何证明可用、还有什么风险。它不是 AI 对话存档，也不是为了填满目录。

## 2. 放置与命名

优先遵守仓库已有约定。没有约定时，建议使用：

```text
docs/
├─ README.md
├─ EVOLUTION.md
├─ 01-总体规划/
├─ 02-需求管理/
├─ 03-架构设计/
├─ 04-详细设计/
├─ 05-开发规范/
├─ 06-测试与质量/
├─ 07-部署运维/
├─ 08-会议与讨论/
├─ 09-亮点总结/
└─ ai-process/
   └─ REQ-001-功能名称/
      ├─ 00-任务说明.md
      ├─ 01-实施计划.md
      ├─ 02-开发日志.md
      ├─ 03-验证记录.md
      └─ 04-交付总结.md
```

推荐编号：`REQ-###`（需求）、`FIX-###`（缺陷）、`TECH-###`（技术任务）、`ADR-###`（架构决策）。没有正式编号时可使用日期加短标题，但不得阻塞紧急修复。

## 3. 任务分级

| 级别 | 判断标准 | 最小文档集合 |
|---|---|---|
| 小型 | 局部、低风险、无契约或数据变化 | 一份 AI 开发记录，可合并需求、实现和验证 |
| 标准 | 新增用户可见能力或跨多个文件/模块 | 需求分析、AI 开发记录、验证记录 |
| 重大 | 核心业务、高风险、跨系统或需要分阶段交付 | 需求分析、技术方案、里程碑、开发记录、验证记录、交付总结 |
| 架构 | 服务边界、公共接口、数据归属、部署拓扑发生变化 | 重大集合，并增加 ADR、迁移、兼容、观测与回滚说明 |

若难以判断，按风险更高一级处理。小任务允许合并文件，但必填信息不能省略。

## 4. 生命周期

### 开发前

- 写清背景、目标、范围和非目标。
- 定义可检查的验收标准。
- 标注假设、未知项、负责人和截止时间。
- 重大任务确定方案、风险、里程碑、兼容和回滚策略。

### 开发中

- 维护里程碑状态和实际变更文件。
- 记录影响维护的重要决策、被否决方案和原因。
- 记录实现相对原计划的偏差。
- 记录 AI 参与范围以及人工审阅情况，不保存内部思维链。

### 交付前

- 写入实际执行的测试、构建、检查或人工验证。
- 区分通过、失败、未执行和不适用。
- 记录已知问题、残余风险、回滚方式和后续责任人。
- 文档与代码一同进入任务、提交或 PR。

## 5. 所有过程文档的公共元数据

```md
- 编号：
- 状态：草稿 / 待评审 / 开发中 / 待验证 / 已完成 / 已废弃
- 负责人：
- 创建日期：
- 最后更新：
- 关联需求/缺陷：
- 关联提交/PR：
```

状态必须反映真实情况。存在关键未验证项时不得标为“已完成”。

## 6. AI 参与记录

至少记录：

- AI 参与的任务：分析、设计、编码、测试建议、文档或审查。
- 提供给 AI 的关键材料和约束摘要。
- AI 产出的文件或建议摘要。
- 人工修改、拒绝或确认了什么。
- 最终验证由谁完成，证据在哪里。

不得记录密码、Token、连接串、生产数据、未脱敏日志或包含这些内容的完整提示词。模型名称和版本仅在团队确有审计要求时记录。

## 7. 验证证据

推荐表格：

```md
| 验证项 | 命令或方法 | 环境 | 结果 | 证据/备注 |
|---|---|---|---|---|
| 单元测试 | `mvn test` | 本地 JDK 21 | 通过，128/128 | 日志链接 |
```

不得用“AI 检查通过”代替测试；不得在未执行时写“通过”。由于环境限制无法运行时，写清限制、影响和建议的后续命令。

## 8. ADR 最小格式

架构决策记录至少包括：背景、决策、备选方案、选择理由、影响、风险、重新评估条件、日期和决策人。一个 ADR 只记录一个重要决策。

## 9. 完成定义

只有满足以下条件才能标记完成：

- 验收标准逐项有结论。
- 实际变更可追溯到文件和提交/PR。
- 所声称的验证均有真实证据。
- 需求、设计与实现偏差已经说明。
- 遗留问题和残余风险有明确状态；需要跟进时有责任人。
- 相关文档已与代码同步更新。

## 10. PR 文档检查清单

```md
- [ ] 已关联需求、缺陷或技术任务编号
- [ ] 已更新需求或技术方案
- [ ] 已记录 AI 实际参与和人工审阅情况
- [ ] 已记录测试命令、方法和实际结果
- [ ] 已说明已知问题、残余风险和后续事项
- [ ] 接口、数据库、部署或运维方式变化时，相关文档已同步
```
